# Руль-симулятор — V1

Первая версия модульного USB HID руля-симулятора.

## Архитектура V1
- Arduino Pro Micro 5V/16MHz (ATmega32U4).
- Инкрементальный квадратурный энкодер руля A/B.
- 3 аналоговые педали: газ, тормоз, сцепление.
- 2 аналоговые оси КПП: X/Y.
- Отдельные физические кнопки: «Зажигание» и «Пов. передача».
- Отдельный концевик центра руля.
- 6 виртуальных HID-кнопок КПП: передачи 1–6.
- Всего **8 HID-кнопок**: зажигание + повышение + 6 передач.
- 4 HID-оси (руль и 3 педали), 0 hats. КПП не публикует аналоговые HID-оси.
- Карта осей: X — руль, Y — газ, Rx — тормоз, Z — сцепление.
- FFB в V1 отсутствует.

## Калибровка
Первый запуск при зажатом «Зажигании» выполняет полную калибровку: ноль/край руля, MIN/MAX педалей, положения передач 1–6 и сохранение в EEPROM.

После сохранения каждый обычный запуск выполняет только калибровку нуля руля.

GEAR_CALIBRATION_MARGIN = 15 находится в прошивке отдельной константой.

Потенциометры X/Y КПП обрабатываются внутри Arduino: контроллер определяет передачу и отправляет только виртуальную кнопку 1–6. Оси КПП в игровом USB HID не объявляются.

## Постоянная отладка и мониторинг
Serial Monitor работает на **115200 baud**. Прошивка постоянно выводит строку `[DBG]` примерно каждые 250 мс: состояние калибровки и этап, энкодер, концевик, кнопки, все пять аналоговых входов, распознанную передачу и режим HID. Во время поиска нуля руля выводятся дополнительные строки `[DBG] ZERO_CAL`. При удержании «Зажигания» во время включения после сохранённой калибровки включается отдельный мониторный режим: датчики продолжают обрабатываться, но `Joystick.sendState()` не вызывается.

Подробная таблица контактов, схема и расшифровка полей отладки: [V1_WIRING.md](docs/V1_WIRING.md).

## Проверка
Проведена статическая проверка: уникальность pin-map, отсутствие матрицы, 8 HID-кнопок, отсутствие старых 3×4/12-button ограничений и согласованность документации. Аппаратная компиляция и тестирование требуют Arduino toolchain и реального устройства.

## Сборка в Arduino IDE

Перед компиляцией установите именно **Arduino Joystick Library by Matthew Heironimus (MHeironimus/ArduinoJoystickLibrary)** через Library Manager или из официального репозитория: https://github.com/MHeironimus/ArduinoJoystickLibrary.

Эта прошивка использует класс `Joystick_` и API этой библиотеки. Другие библиотеки с похожим именем `Joystick.h` несовместимы и приводят к ошибке `'Joystick_' does not name a type`. Если ошибка остаётся после установки, удалите/переименуйте конфликтующую библиотеку из папки Arduino `libraries`, перезапустите IDE и проверьте путь к подключённому `Joystick.h` в подробном выводе компиляции.

В Arduino IDE выберите плату **SparkFun Pro Micro** и правильный вариант **ATmega32U4, 5V, 16 MHz**. Прошивка использует встроенную библиотеку Arduino `EEPROM`. MCP23017 и I²C в V1 не используются.

Проверка, выполняемая только статически, не заменяет компиляцию с указанной платой и библиотекой и проверку на реальном контроллере.
