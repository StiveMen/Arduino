# Руль-симулятор V1 — схема подключения

Контроллер: **Arduino Pro Micro, ATmega32U4, 5 V / 16 MHz**. В V1 нет матрицы кнопок, MCP23017, светодиодов и мотора Force Feedback. Каждый орган управления подключается напрямую к Pro Micro.

## 1. Карта подключений

| Узел | Контакт узла | Контакт Pro Micro | Примечание |
|---|---|---|---|
| Потенциометр газа | ползунок | A1 | Аналоговый вход |
| Потенциометр тормоза | ползунок | A2 | Аналоговый вход |
| Потенциометр сцепления | ползунок | A3 | Аналоговый вход |
| Потенциометр КПП X | ползунок | A8 | Внутренняя обработка координат |
| Потенциометр КПП Y | ползунок | A9 | Внутренняя обработка координат |
| Энкодер руля | канал A / CLK | D0 | Канал энкодера |
| Энкодер руля | канал B / DT | D1 | Канал энкодера |
| Энкодер руля | COM / GND | GND | Общая земля |
| Кнопка «Зажигание» | контакт 1 | D5 | Вход с внутренней подтяжкой |
| Кнопка «Зажигание» | контакт 2 | GND | При нажатии замыкается на GND |
| Концевик центра руля | COM | GND | Общий контакт |
| Концевик центра руля | NO | D6 | Срабатывание при замыкании на GND |
| Кнопка «Повышенная передача» | контакт 1 | D7 | Вход с внутренней подтяжкой |
| Кнопка «Повышенная передача» | контакт 2 | GND | При нажатии замыкается на GND |

У каждого потенциометра крайние выводы подключаются к 5V/VCC и GND, средний вывод — к указанному аналоговому входу. Все датчики должны иметь общий GND.

## 2. Схема сигналов

```text
Arduino Pro Micro 5V / 16 MHz

Газ: ползунок       -> A1
Тормоз: ползунок    -> A2
Сцепление: ползунок -> A3
КПП X: ползунок     -> A8
КПП Y: ползунок     -> A9

Энкодер A           -> D0
Энкодер B           -> D1
Зажигание           -> D5 -> кнопка -> GND
Концевик центра     -> D6 -> концевик -> GND
Повышенная передача -> D7 -> кнопка -> GND

5V/VCC -> крайние выводы потенциометров
GND    -> общая земля потенциометров и кнопок
USB    -> ПК
```

## 3. Проверка перед подачей питания

1. Отключите USB и проверьте отсутствие короткого замыкания между 5V и GND.
2. Проверьте общий GND для датчиков и кнопок.
3. Убедитесь, что кнопки и концевик замыкают вход на GND, а не на 5V.
4. Подключите USB и откройте Serial Monitor на **115200 baud**.
5. Перемещайте по одному органу управления и наблюдайте за `ADC_GAS`, `ADC_BRAKE`, `ADC_CLUTCH`, `ADC_GEAR_X`, `ADC_GEAR_Y`, `ENC_RAW`, `IGN`, `HIGH_BTN` и `CENTER_SW`.

## 4. Постоянная отладка

Каждые 250 мс прошивка выводит состояние EEPROM-калибровки, этап, энкодер, концевик, кнопки, аналоговые входы, текущую передачу и состояние HID. Во время поиска нуля руля дополнительно выводится `[DBG] ZERO_CAL`.

- `ADC_GAS / ADC_BRAKE / ADC_CLUTCH` — сырые значения педалей.
- `ADC_GEAR_X / ADC_GEAR_Y` — сырые значения потенциометров КПП.
- `ENC_RAW` — счёт энкодера; `ENC_ZEROED` — значение относительно найденного нуля.
- `CENTER_SW=PRESSED` — концевик замкнут на GND; `OPEN` — разомкнут.
- `IGN=1`, `HIGH_BTN=ON` — соответствующая кнопка нажата.
- `GEAR=0` — нейтраль или неоднозначная позиция; `GEAR=1..6` — распознанная передача.

Не подключайте и не отключайте провода при включённом питании. Распиновку нельзя менять без явного разрешения пользователя.
