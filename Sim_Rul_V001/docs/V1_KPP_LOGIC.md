# КПП V1 — логика

## Входы
- X-потенциометр КПП.
- Y-потенциометр КПП.
- Отдельная физическая кнопка «Пов. передача».

Передачи 1–6 — виртуальные HID-кнопки. Отдельных физических кнопок 1–6 нет.

## Калибровка положений
На первом запуске контроллер по очереди запоминает текущие координаты X/Y для передач 1–6.

GEAR_CALIBRATION_MARGIN = 15.

Запас расширяет точку в квадрат X±15 / Y±15. Если зоны двух передач пересекаются, контроллер считает положение нейтральным.

## Передачи 1–6
- вошли в зону передачи → соответствующая HID-кнопка ON;
- вышли из зоны → соответствующая HID-кнопка OFF;
- фиксации положения передачи нет;
- запоминания предыдущей передачи нет.

## Пов. передача
1. Нажать физическую кнопку «Пов. передача».
2. Войти в положение передачи.
3. Повышение становится активным.
4. Отпустить физическую кнопку — состояние остаётся активным, пока КПП остаётся в передаче.
5. Выйти из передачи — состояние сбрасывается, если физическая кнопка уже отпущена.
6. Если кнопка всё ещё удерживается при выходе из передачи, повышение остаётся активным.

## HID-кнопки
- 0–19 — 20 матричных кнопок.
- 20 — Зажигание.
- 21 — Пов. передача.
- 22–27 — виртуальные передачи 1–6.

## Аналоговые датчики и HID
- Потенциометры КПП X/Y считываются и обрабатываются внутри Arduino.
- По координатам X/Y Arduino определяет выбранную передачу.
- В USB HID передаются только виртуальные кнопки передач 1–6 (ID 22–27).
- Оси Ry/Rz КПП не объявляются и не отправляются в игровой контроллер.
- HID-оси остаются только для руля (X), газа (Y), тормоза (Z) и сцепления (Rx).
