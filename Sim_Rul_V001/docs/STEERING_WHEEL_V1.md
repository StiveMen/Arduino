# Руль-симулятор — версия 1.0

## Назначение
V1 — модульный проводной USB HID руль-симулятор на Arduino Pro Micro 5V/16MHz (ATmega32U4), без расширителей ввода-вывода и матрицы кнопок.

## Состав V1
- Квадратурный энкодер руля A/B.
- 3 аналоговые педали.
- 2 аналоговые оси КПП X/Y.
- Отдельная физическая кнопка «Зажигание».
- Отдельная физическая кнопка «Пов. передача».
- Концевик центра руля.
- USB HID: **8 кнопок, 4 оси, 0 hats**. Оси КПП не публикуются.
- FFB в V1 отсутствует.

## HID-карта
| ID | Источник |
|---:|---|
| 0 | Зажигание |
| 1 | Пов. передача |
| 2–7 | Виртуальные передачи 1–6 |

Оси HID: X — руль, Y — газ, Rx — тормоз, Z — сцепление. Сцепление передаётся через Z; тормоз перенесён на Rx, чтобы обе педали имели отдельные HID-оси. Потенциометры КПП X/Y обрабатываются локально Arduino; игра получает только кнопки передач 1–6 (HID 2–7).

## GPIO
### Pro Micro
- A0 — газ
- A1 — тормоз
- A2 — сцепление
- A3 — КПП X
- A6 — КПП Y
- D0/D1 — энкодер
- D5 — Зажигание
- D6 — Пов. передача
- D7 — концевик

## Руль и ноль
При каждом включении:

RIGHT → LEFT → срабатывание концевика → сброс энкодера → отпускание концевика → найден ноль → RIGHT-проверка.

После нахождения нуля концевик игнорируется до следующего включения.

## Полная первая калибровка
1. Калибровка нуля руля.
2. Крайнее положение руля.
3. MIN педалей.
4. MAX педалей.
5. Координаты передач 1–6.
6. Нейтраль + удержание «Зажигание» → EEPROM save.

## КПП
Положение 1–6 определяется по X/Y внутри Arduino. Вход в зону включает соответствующую виртуальную HID-кнопку, выход выключает. Фиксации передачи нет. Аналоговые оси КПП не передаются в USB HID.

GEAR_CALIBRATION_MARGIN = 15.

### Пов. передача
Состояние может быть физическим или защёлкнутым в выбранной передаче. При выходе из передачи защёлка снимается, если физическая кнопка отпущена.

## Монитор
После сохранённой калибровки удержание «Зажигание» при включении выбирает мониторинг. Все входы продолжают обрабатываться, но Joystick.sendState() не вызывается.

## EEPROM
Сохраняются край руля, MIN/MAX педалей, X/Y шести передач, magic/version/checksum. Ноль руля определяется заново при каждом включении.

## Ограничения
- Матрица кнопок и расширители GPIO в V1 не используются.
- Нужна установка/проверка Arduino core для Pro Micro и библиотеки Joystick.
- Полная аппаратная компиляция и тестирование требуют реального устройства.
