# Руль-симулятор V1 — схема подключения

Контроллер: **Arduino Pro Micro, ATmega32U4, 5 V / 16 MHz**. В V1 нет матрицы кнопок, MCP23017, светодиодов и мотора обратной связи. Каждый элемент подключается напрямую к Pro Micro.

## 1. Карта подключений

| Узел | Контакт узла | Контакт Pro Micro | Примечание |
|---|---|---|---|
| Потенциометр газа | один крайний вывод | VCC / 5V | Питание датчика |
| Потенциометр газа | второй крайний вывод | GND | Общая земля |
| Потенциометр газа | средний вывод (ползунок) | A0 | Аналоговое значение |
| Потенциометр тормоза | крайний вывод | VCC / 5V | Питание датчика |
| Потенциометр тормоза | второй крайний вывод | GND | Общая земля |
| Потенциометр тормоза | ползунок | A1 | Аналоговое значение |
| Потенциометр сцепления | крайний вывод | VCC / 5V | Питание датчика |
| Потенциометр сцепления | второй крайний вывод | GND | Общая земля |
| Потенциометр сцепления | ползунок | A2 | Аналоговое значение |
| Потенциометр КПП X | крайний вывод | VCC / 5V | Питание датчика |
| Потенциометр КПП X | второй крайний вывод | GND | Общая земля |
| Потенциометр КПП X | ползунок | A3 | Аналоговое значение |
| Потенциометр КПП Y | крайний вывод | VCC / 5V | Питание датчика |
| Потенциометр КПП Y | второй крайний вывод | GND | Общая земля |
| Потенциометр КПП Y | ползунок | A6 | Аналоговое значение |
| Квадратурный энкодер руля | канал A / CLK | D0 | Канал энкодера |
| Квадратурный энкодер руля | канал B / DT | D1 | Канал энкодера |
| Энкодер руля | GND / общий контакт | GND | Общая земля |
| Кнопка «Зажигание» | контакт 1 | D5 | Вход с внутренней подтяжкой |
| Кнопка «Зажигание» | контакт 2 | GND | Не подключать к 5V |
| Кнопка «Повышенная передача» | контакт 1 | D6 | Вход с внутренней подтяжкой |
| Кнопка «Повышенная передача» | контакт 2 | GND | Не подключать к 5V |
| Концевик центра руля | COM | GND | Общий контакт |
| Концевик центра руля | NO | D7 | Замыкается при срабатывании |

**Важно:** если у энкодера есть выводы VCC и GND, VCC подключайте согласно маркировке самого модуля. Для обычного пассивного энкодера с контактами A/B/COM подключите COM к GND, а A и B — к D0 и D1. Не подавайте 5 V на аналоговые входы через ползунки при питании Pro Micro 3.3 V — эта прошивка рассчитана на плату 5 V / 16 MHz.

## 2. Общая схема

```text
                       Arduino Pro Micro 5V
                    ┌────────────────────────┐
Газ: ползунок ──────┤ A0                     │
Тормоз: ползунок ───┤ A1                     │
Сцепление: ползунок ┤ A2                     │
КПП X: ползунок ────┤ A3                     │
КПП Y: ползунок ────┤ A6                     │
Энкодер A ──────────┤ D0                     │
Энкодер B ──────────┤ D1                     │
Кнопка зажигания ───┤ D5                     │
Кнопка повыш. ──────┤ D6                     │
Концевик центра ────┤ D7                     │
                    │ 5V/VCC ── питание POT   │
                    │ GND ───── общий GND     │
                    └───────────┬────────────┘
                                │ USB
                                ▼
                         ПК / Serial Monitor
```

У всех потенциометров крайние выводы подключаются к 5V и GND, а средний вывод — к соответствующему аналоговому входу. Если направление значения неправильное, поменяйте местами два крайних вывода потенциометра.

## 3. Проверка перед подачей питания

1. Отключите USB и проверьте отсутствие короткого замыкания между 5V и GND.
2. Проверьте, что все датчики используют общий GND.
3. Убедитесь, что D5, D6 и D7 замыкаются на GND, а не на 5V.
4. Подключите USB и откройте Serial Monitor на **115200 baud**.
5. Перемещайте по одному органу управления и наблюдайте за соответствующими значениями `ADC_...`, `ENC_RAW`, `IGN`, `HIGH_BTN` и `CENTER_SW`.

## 4. Постоянная отладка

Каждые 250 мс прошивка выводит строку `[DBG]` с состоянием EEPROM-калибровки, этапом, энкодером, концевиком, обеими кнопками, пятью аналоговыми входами, текущей передачей и состоянием HID. Во время поиска нуля руля дополнительно выводится `[DBG] ZERO_CAL`.

- `ADC_GAS / ADC_BRAKE / ADC_CLUTCH` — сырые значения педалей, обычно в диапазоне 0–1023.
- `ADC_GEAR_X / ADC_GEAR_Y` — сырые значения потенциометров КПП.
- `ENC_RAW` — накопленный счёт энкодера; `ENC_ZEROED` — значение относительно найденного нуля.
- `CENTER_SW=PRESSED` — концевик замкнут на GND; `OPEN` — разомкнут.
- `IGN=1`, `HIGH_BTN=1` — соответствующая кнопка нажата.
- `GEAR=0` — нейтраль/неоднозначная позиция; `GEAR=1..6` — распознанная передача.
- `CAL=INVALID` означает, что калибровка отсутствует или не прошла проверку EEPROM.

Не подключайте и не отключайте провода при включённом питании.
