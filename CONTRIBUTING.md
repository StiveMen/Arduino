# Как работать с проектом

Спасибо за интерес к проекту **Sim_Rul**.

## Перед изменениями

1. Прочитайте [описание V1](Sim_Rul_V001/README.md).
2. Сверьтесь с [полной спецификацией](Sim_Rul_V001/docs/STEERING_WHEEL_V1.md) и [распиновкой](Sim_Rul_V001/docs/V1_WIRING.md).
3. Не переносите в V1 функции, которые отложены на будущие версии.
4. Сохраняйте документацию согласованной с прошивкой.

## Ограничения V1

- Контроллер: Arduino Pro Micro, ATmega32U4, 5 V / 16 MHz.
- Руль и три педали публикуются как аналоговые USB HID-оси.
- КПП использует входы X/Y внутри прошивки и передаёт в HID только кнопки передач 1–6.
- Аналоговые оси КПП в USB HID не публикуются.
- MCP23017, матрица кнопок и Force Feedback в V1 не используются.

## Стиль изменений

- Используйте понятные имена и комментарии там, где логика неочевидна.
- Не меняйте назначение контактов без обновления таблицы в документации.
- Не заявляйте о компиляции или аппаратном тестировании, если они не выполнялись.
- Разделяйте изменения прошивки и документации по смыслу.
- Перед отправкой проверьте ссылки, номера контактов, условия калибровки и поведение HID.

## Проверка перед публикацией

- [ ] Код соответствует спецификации V1.
- [ ] Нет конфликтующих назначений контактов.
- [ ] Документация обновлена.
- [ ] Указано, какие проверки реально выполнены.
- [ ] Новые зависимости описаны.

Для изменений, требующих аппаратной проверки, укажите плату, версии библиотек и результаты тестирования.
