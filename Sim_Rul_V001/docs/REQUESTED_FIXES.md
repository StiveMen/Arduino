# Sim_Rul V1 — исправления

Текущая конфигурация: **без матрицы кнопок**, без MCP23017, без светодиодов и без Force Feedback. Назначения контактов нельзя менять без явного разрешения пользователя.

## Распиновка

| Узел | Контакт Pro Micro |
|---|---|
| Газ | A1 |
| Тормоз | A2 |
| Сцепление | A3 |
| Потенциометр КПП X | A8 |
| Потенциометр КПП Y | A9 |
| Энкодер руля A | D0 |
| Энкодер руля B | D1 |
| Зажигание | D5 |
| Концевик центра руля | D6 |
| Кнопка повышенной передачи | D7 |

## Кнопки и оси

- 1 кнопка зажигания.
- 1 отдельная физическая кнопка повышенной передачи.
- 6 виртуальных кнопок передач, определяемых по координатам потенциометров КПП X/Y.
- Всего **8 HID-кнопок**.
- HID-оси: руль, газ, тормоз и сцепление.
- Координаты КПП X/Y обрабатываются внутри Arduino и не передаются как HID-оси.

## Логика повышенной передачи

1. Если пользователь удерживает физическую кнопку повышенной передачи и вводит рычаг в одну из передач 1–6, повышенная передача защёлкивается.
2. Если отпустить физическую кнопку, пока рычаг остаётся в выбранной передаче, защёлка остаётся активной.
3. При выходе из передачи повышенная передача отключается, если физическая кнопка уже отпущена.
4. Если пользователь выходит из передачи, продолжая удерживать физическую кнопку, повышенная передача остаётся активной; отпускание кнопки в нейтрали снимает защёлку.
5. Если передача выбрана без нажатия физической кнопки повышения, повышенная передача не включается.

## Монитор

- После сохранённой калибровки удержание зажигания при включении выбирает режим Serial Monitor.
- В режиме мониторинга продолжается чтение руля, педалей, координат КПП и кнопок.
- В режиме мониторинга **нельзя отправлять состояние USB HID** через `Joystick.sendState()`.
- В Serial выводятся руль, значения и пределы педалей, координаты X/Y КПП, зажигание, физическая кнопка повышенной передачи и статусы передач 1–6.

## Калибровка и проверка

- Существующая последовательность калибровки должна сохраняться.
- Код сохранён в репозитории, но компиляция и проверка на физическом устройстве ещё не подтверждены.
