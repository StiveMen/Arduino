## 🚗 Sim_Rul — руль-симулятор

Разработка собственного USB-контроллера для гоночных симуляторов на **Arduino Pro Micro (ATmega32U4)**.

| Возможность | Реализация V1 |
|---|---|
| Руль | Энкодер, USB HID-ось |
| Педали | Газ, тормоз, сцепление — аналоговые оси |
| КПП | Аналоговые X/Y внутри контроллера → виртуальные кнопки передач 1–6 |
| Кнопки | Зажигание, повышенная передача и передачи 1–6 |
| Калибровка | Первичная настройка с сохранением в EEPROM |
| Отладка | Serial Monitor, 115200 baud |
| Force Feedback | Не входит в V1 |

## 📌 Состояние проекта

**V1 находится в разработке.** Документация и прошивка подготовлены для дальнейшей проверки; перед использованием необходимо собрать проект, проверить распиновку и испытать устройство на реальном оборудовании.

## 🛠️ Основная платформа

- Arduino Pro Micro, ATmega32U4, 5 V / 16 MHz
- Arduino IDE
- Arduino Joystick Library by Matthew Heironimus
- EEPROM для сохранения параметров калибровки

> Перед загрузкой прошивки сверяйтесь с документацией V1. Не подключайте питание до проверки соединений и общей земли.
