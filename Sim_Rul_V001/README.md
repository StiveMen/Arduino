## О проекте

**Sim_Rul** — проект самостоятельного USB HID-контроллера, который объединяет руль, педали и механическую КПП. V1 ориентирована на простую конструкцию и возможность отладки без дополнительных расширителей портов.

## Возможности V1

| Узел | Как работает |
|---|---|
| Руль | Квадратурный инкрементальный энкодер A/B |
| Центр руля | Концевик для поиска нулевого положения |
| Педали | Газ, тормоз и сцепление — аналоговые USB HID-оси |
| КПП | Два аналоговых входа X/Y распознаются прошивкой как передачи 1–6 |
| Кнопки | Отдельные кнопки зажигания и повышенной передачи |
| Сохранение | Параметры калибровки записываются в EEPROM |
| Диагностика | Serial Monitor на скорости 115200 baud |
| Force Feedback | Не предусмотрен в V1 |

### USB HID

- **4 оси:** X — руль, Y — газ, Rx — тормоз, Z — сцепление.
- **8 кнопок:** зажигание, повышенная передача и шесть передач КПП.
- **0 hat switch.**
- Аналоговые оси КПП X/Y используются внутри прошивки и **не передаются** в USB HID.

## Оборудование

- Arduino Pro Micro, ATmega32U4, 5 V / 16 MHz.
- Квадратурный энкодер руля.
- Концевой выключатель.
- Три потенциометра педалей.
- Два потенциометра КПП X/Y.
- Кнопки зажигания и повышенной передачи.
- Провода и соединители согласно таблице подключения.

> Перед сборкой сверьте точную распиновку с [V1_WIRING.md](docs/V1_WIRING.md). Не подключайте неизвестные контакты наугад.

## Установка и прошивка

1. Установите [Arduino IDE](https://www.arduino.cc/en/software).
2. Установите **Arduino Joystick Library by Matthew Heironimus** через Library Manager или официальный репозиторий: [MHeironimus/ArduinoJoystickLibrary](https://github.com/MHeironimus/ArduinoJoystickLibrary).
3. Откройте файл `src/Sim_Rul_V1/Sim_Rul_V1.ino`.
4. В Arduino IDE выберите плату **SparkFun Pro Micro** и вариант **ATmega32U4, 5 V, 16 MHz**.
5. Подключите плату, выберите соответствующий порт и выполните компиляцию.
6. После успешной компиляции загрузите прошивку и проверьте устройство.

### Важное замечание о библиотеке

Прошивка использует класс `Joystick_` из Arduino Joystick Library by Matthew Heironimus. Библиотеки с похожим названием могут быть несовместимы и вызывать ошибку `'Joystick_' does not name a type`.

Если ошибка появляется после установки библиотеки, проверьте, какую именно `Joystick.h` Arduino IDE подключает в подробном выводе компиляции, удалите конфликтующую копию при необходимости и перезапустите IDE.

MCP23017 и I²C в V1 не используются. Для сохранения настроек применяется встроенная библиотека Arduino `EEPROM`.

## Калибровка

### Первичная настройка

1. Удерживайте кнопку **«Зажигание»** при включении контроллера.
2. Выполните последовательность калибровки руля, педалей и передач, следуя [инструкции по калибровке](docs/V1_CALIBRATION.md).
3. Сохраните параметры в EEPROM по предусмотренной последовательности.
4. Проверьте распознавание передач и полный диапазон всех осей.

### Обычный запуск

После сохранения настроек обычный запуск выполняет калибровку нуля руля. Полная настройка запускается отдельно при удержании кнопки зажигания во время включения.

Параметр `GEAR_CALIBRATION_MARGIN = 15` вынесен в отдельную константу прошивки для удобной настройки.

## Мониторинг и диагностика

Откройте Serial Monitor и установите скорость **115200 baud**.

Прошивка выводит диагностическую строку `[DBG]` примерно каждые 250 мс. В ней отображаются этап калибровки, значение энкодера, состояние концевика и кнопок, аналоговые входы, распознанная передача и режим HID. Во время поиска нуля дополнительно выводятся сообщения `[DBG] ZERO_CAL`.

После сохранения калибровки удержание кнопки «Зажигание» при включении запускает мониторный режим: датчики продолжают считываться, но `Joystick.sendState()` не вызывается. Это позволяет проверять входы без отправки состояний в USB HID.
